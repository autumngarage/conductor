## What shipped

- `conductor exec` dirty-worktree scope checks now preserve single-column git
  status paths instead of dropping them from the boundary calculation.
- Merge-gate semantic review now runs in a temporary detached worktree, keeping
  reviewer-side scratch mutations out of the merge candidate checkout.
- Gemini CLI `call` mode now gets a concrete default timeout when the user does
  not pass `--timeout`, while explicit timeout overrides stay exact.
- Gemini-routed prompts that ask for external source URLs or citations now warn
  that Conductor does not verify provider-generated links.
- Semantic ask/call guidance remains constrained to `kind` and `effort`, with
  provider/model pinning kept on the lower-level command surfaces.
- The release workflow passed source validation, bumped the Homebrew tap,
  installed the released formula, and smoked the released binary.
