> Hardened the merge-review wrapper against a Codex failure mode where a
> reviewer emits `CODEX_REVIEW_BLOCKED` without actionable findings, causing
> the fix loop to mutate code without a concrete defect to repair.

## What shipped

- `scripts/codex-review.sh` now counts actionable finding bullets before
  treating a `CODEX_REVIEW_BLOCKED` verdict as fixable.
- `BLOCKED` without actionable findings is treated as malformed review output:
  it first uses the existing one-shot Conductor fallback retry path, then
  follows `on_error` if no fallback produces a trustworthy verdict.
- The fix phase is never entered for zero-finding `BLOCKED` output, preserving
  the read-only review boundary and preventing style-only churn.
- Regression coverage now exercises both fallback-disabled fail-closed handling
  and fallback-enabled recovery to a clean alternate-provider verdict.
